# Rafaella Bressan — Portfólio

Portfólio de desenvolvimento web com melhorias pontuais sobre o layout original.

A identidade foi preservada: preto, branco e cinza, marca RB, fontes Playfair Display e Inter, título “Sites que transformam negócios.”, foto de abertura, seção Sobre, três projetos em grade, lista de seis serviços, contato claro e rodapé escuro.

## Melhorias

- Textos mais claros para quem tem um comércio ou presta serviços.
- Projetos de demonstração identificados como autorais, com contexto e links para pedir um site semelhante.
- Serviços com descrições visíveis e acesso direto ao WhatsApp com uma mensagem específica.
- Imagens PNG dos projetos atualizadas pela autora preservadas.
- Menu móvel acessível, navegação por teclado e respeito à preferência por movimento reduzido.
- Conteúdo disponível sem JavaScript e abertura sem espera artificial.
- Fontes locais com as respectivas licenças em `assets/fonts/`.

## Abrir e editar

Abra `index.html` no navegador. O site usa HTML, CSS e JavaScript, sem instalação ou compilação.

- `index.html`: textos, imagens, serviços, projetos e contatos.
- `css/style.css`: aparência original e refinamentos.
- `css/responsive.css`: adaptações para celular e tablet.
- `css/animations.css`: animações discretas.
- `css/fonts.css` e `assets/fonts/`: tipografia.
- `js/main.js`: menu e navegação.

As mensagens dos links de WhatsApp são apenas preenchidas; o visitante decide se deseja enviá-las. Os projetos continuam apontando para as três demonstrações existentes.
