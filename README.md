# Rafaella Bressan — Portfólio

Portfólio autoral de desenvolvimento web, com identidade em preto, branco e cinza, títulos em Playfair Display e textos em Inter.

## Esta reformulação

- Apresentação inicial com uma única foto e caminhos claros para projetos e orçamento.
- Projetos apresentados individualmente, com contexto, recursos e links para as demonstrações.
- Estudos autorais identificados como projetos conceito, sem números de clientes ou resultados inventados.
- Seis serviços com detalhes expansíveis e mensagens específicas para iniciar uma conversa no WhatsApp.
- Seções de apresentação pessoal e etapas de desenvolvimento.
- Navegação móvel com indicação de estado, fechamento por Escape e retorno de foco.
- Conteúdo disponível sem JavaScript e animações que respeitam a preferência por movimento reduzido.
- Fontes locais, com as respectivas licenças incluídas.

## Abrir

Abra `index.html` em um navegador. O site é estático e não exige instalação ou compilação.

## Arquivos

- `index.html`: conteúdo, projetos, serviços e contatos.
- `css/style.css`: identidade e componentes principais.
- `css/responsive.css`: ajustes para diferentes larguras de tela.
- `css/animations.css`: movimentos discretos e acessibilidade de animações.
- `css/fonts.css` e `assets/fonts/`: fontes utilizadas e licenças.
- `js/main.js`: menu, indicação da seção atual e entrada suave de conteúdo.
- `assets/img/`: foto pessoal e prévias dos projetos do portfólio original.
- `js/loader.js`: arquivo de compatibilidade; não é carregado. O site abre sem tela de espera artificial.

## Atualizar conteúdo

Edite os textos e os links diretamente no HTML. Cada link de WhatsApp contém uma mensagem pronta, que o visitante pode revisar antes de enviar. Nenhuma mensagem é enviada automaticamente pelo site.

As demonstrações continuam apontando para os endereços existentes de Bella Massa, Studio Éclat e Don Barber. As imagens de apresentação foram preservadas do portfólio original; ao publicar uma nova versão de um projeto, atualize também sua captura em `assets/img/projects/`.

## Publicação

O projeto mantém a estrutura compatível com a configuração atual do GitHub Pages. Esta reformulação é preparada em uma branch de revisão; a versão pública só muda após a integração das alterações na branch usada pelo Pages.
